Privacy Policy – ProbeClock ProbeClock Widget does not collect, sell, or share personal data. The app connects to the public NASA/JPL Horizons service to retrieve spacecraft distance, one-way light time, mission age, and relative velocity data for Voyager 1, Voyager 2, Pioneer 10, and Pioneer 11. The displayed spacecraft data is referenced to the center of Earth. ProbeClock stores only local app data on the user’s device, including selected unit preferences, selected spacecraft, widget settings, and local emergency backup data. This data is not transmitted to the developer. The app does not require a user account. The app does not collect location data. The app does not use advertising SDKs. The app does not use analytics SDKs. The app does not access contacts, photos, microphone, camera, or precise device location. The feedback button opens the user’s email app and allows the user to voluntarily send feedback to the developer. The app itself does not automatically collect or transmit email addresses or message content. Local backup data can be removed by uninstalling the app or clearing the app’s storage in Android settings. Location data Voyager & Space Object Tracker can optionally use the device location when the user selects “Own location” as the reference point instead of “Earth center”. The location is used only to calculate distance, one-way light time and relative velocity relative to the user’s own position. For this calculation, the selected coordinates may be sent to the public JPL Horizons service as part of the Horizons request. Using the app with “Earth center” as reference does not require location access. Location access is optional and can be denied or disabled by the user at any time in Android settings. The app does not use location data for advertising, analytics, user tracking or profiling. The developer does not operate a separate server for storing location data.
